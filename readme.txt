INFORMASI RILIS PERANGKAT LUNAK
OMEGA MX - BATCH PRINTING & QC SYSTEM (Versi 5.0 Stable)
========================================================================

Terima kasih telah memilih solusi otomasi industri dari PT SMARTEK SISTEM INOVASI.

1. DESKRIPSI SISTEM
Omega MX System adalah aplikasi HMI (Human Machine Interface) kustom yang 
dirancang khusus untuk mengelola produksi Batch Printing menggunakan 
Thermal Inkjet Omega, yang terintegrasi langsung dengan Scanner Keyence (QC Judgement),
dan sistem Modbus I/O (Sensor & Tower Lamp).

2. FITUR TERBARU DI VERSI 5.0 (UPDATE MAR 2026)
- [NEW] Modular Architecture: Performa aplikasi jauh lebih ringan, stabil, dan bebas lag.
- [NEW] Smart Printer Auto-Start: Mesin melakukan pemanasan (CLR & RESET) diam-diam di belakang layar.
- [NEW] Independent Multithreading: Proses komunikasi ke Mesin Printer, Scanner, dan Sensor Modbus kini berjalan di jalurnya masing-masing.
- [NEW] Auto-Save History: Data Batch dan Judgement otomatis diekspor ke format Excel beserta pencatatan ke Master CSV Log.
- [NEW] Web Analytics Dashboard: Pemantauan produksi (OEE/NG Level) terintegrasi via local web server (Port 5022).
- [NEW] Peningkatan stabilitas pada Mode Simulasi.

3. KEBUTUHAN SISTEM & INSTALASI
- OS Minimal: Windows 10 / 11 (64-bit).
- Kebutuhan Jaringan: Kabel LAN (TCP/IP) terhubung ke Printer (Port 6007) dan Scanner (Port 9004).
- Untuk instalasi, pastikan Anda menggunakan hak akses Administrator (Run as Administrator).
- Anda akan memerlukan Serial Number resmi untuk melanjutkan proses instalasi.
